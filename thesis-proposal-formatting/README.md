# 开题报告排版

使用 `docx-master` 技能对《首都医科大学学位论文开题报告》进行了学术化、正式化排版。

## 排版要求

- **正文**：宋体、小四号（12pt）、1.5 倍行间距。
- 其余格式在满足"学术、正式、美观"的前提下自行安排。
- 输出为可正常编辑的 Word 版本（原文件不被修改）。

## 最终排版规范

| 角色 | 字体 | 字号 | 其它 |
|------|------|------|------|
| 正文（Body Text） | 宋体 / Times New Roman | 小四 12pt | 1.5 倍行距、首行缩进 2 字符、两端对齐 |
| 一级标题（一、～十、） | 黑体 | 小三 15pt | 段前 12pt / 段后 6pt、大纲级别 1 |
| 二级标题（1. / 4.1 …） | 黑体 | 小四 12pt | 段前 6pt / 段后 3pt、大纲级别 2 |
| 三级标题（1）2）…） | 宋体加粗 | 小四 12pt | 段前 6pt / 段后 3pt、大纲级别 3 |
| 参考文献（[N] …） | 宋体 / Times New Roman | 小四 12pt | 1.5 倍行距、左对齐 |

## 处理说明

- **字体统一**：正文原为仿宋 / 宋体 / `Songti SC` 混排，统一为宋体（西文 Times New Roman）；行距原为单倍与 1.5 倍混用，统一为 1.5 倍。
- **标题层级**：为十个一级栏目及各级子标题建立"黑体 / 宋体加粗"层级，并写入大纲级别，Word 导航窗格可直接跳转。
- **保留表单结构**：封面信息表（姓名 / 学号 / 专业 / 导师 / 题目等）、正文中原有的手动 / 自动编号、技术路线图、页面设置（A4）以及底部"备注"说明均按原样保留，仅调整需要统一的排版属性。
- **标题（首页大标题）与"摘要 / Abstract"小标题**按原样保留。

## 复现方式

排版通过声明式配置一次性完成，未手工改动 XML：

```bash
node skills/docx-master/scripts/apply.js thesis-proposal-formatting/format-config.json
```

`format-config.json` 中：`styles[]` 定义正文与三级标题样式；`pattern_rules` / `assignments` 按文本形态与段落编号分配角色；`bulk_rules` 按视觉指纹归并正文；`exclude` 保护封面信息表与备注。原文件路径为 `source`，输出为 `output`（每次运行生成全新文件，原件绝不改动）。
